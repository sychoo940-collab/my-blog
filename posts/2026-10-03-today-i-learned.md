Claude Code와 함께 프레임워크 없이 블로그를 만들면서, 웹의 세 가지 기본 기술이 각각 무엇을 맡는지 몸으로 익혔습니다.

## HTML — 구조

페이지에 **무엇이 있는지**를 정합니다. 이 블로그에서는 `header`, `main`, `article`, `footer` 같은 시맨틱 태그로 뼈대를 만들었습니다.

- 글 제목은 `h1`, 날짜는 `time`, 목록은 `ul`처럼 의미에 맞는 태그를 쓰면 접근성과 검색에 유리합니다.
- 내용이 비어 있어도 구조는 HTML이 먼저 잡아 둡니다.

## CSS — 모양

**어떻게 보일지**를 정합니다. 색, 글꼴, 여백, 반응형 레이아웃이 모두 여기서 결정됩니다.

- **CSS 변수**로 색을 한곳에 모아 두면 다크모드는 변수 값만 바꾸면 됩니다.
- **미디어쿼리**로 모바일에서 데스크톱까지 같은 HTML을 다르게 보여줍니다.
- 한글 본문은 `word-break: keep-all`과 넉넉한 줄간격이 읽기 편했습니다.

```css
:root { --bg: #fcfcfb; }
[data-theme='dark'] { --bg: #14161a; }
```

## JavaScript — 동작

**무엇이 일어나는지**를 정합니다. 이 블로그에서는 세 가지 일을 합니다.

1. `fetch()`로 `posts/` 폴더의 마크다운 파일을 읽어 옵니다.
2. `marked`로 마크다운을 HTML로 바꿔 화면에 넣습니다.
3. 다크모드 버튼을 누르면 선택을 `localStorage`에 저장합니다.

## 한 줄 정리

| 기술 | 역할 | 이 블로그에서 |
| --- | --- | --- |
| HTML | 구조 | 페이지 뼈대, 시맨틱 태그 |
| CSS | 모양 | 테마, 반응형, 타이포그래피 |
| JavaScript | 동작 | 글 불러오기, 변환, 테마 전환 |

> 구조는 HTML, 모양은 CSS, 동작은 JavaScript. 역할을 나눠 생각하니 코드를 어디서 고칠지 훨씬 분명해졌습니다.
